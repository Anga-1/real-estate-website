# Real Estate Website

A realtor-focused website built as a learning and portfolio project while developing practical skills in HTML, CSS, JavaScript, Git, and GitHub.

## Project Overview

This project is designed as the **digital storefront of a modern real estate agent**.

The website allows potential clients to:

* Browse properties for sale and rent
* View detailed property information
* Learn about the realtor and their services
* Contact the realtor
* Enquire about properties
* Request property viewings
* Submit qualified buying, selling, renting, and letting enquiries

The primary objective is to turn a website visitor into a **qualified real-estate lead**.

## Product Direction

The project originally began as a more generic real-estate platform concept.

After reviewing the product direction, it was intentionally changed into a **realtor-focused website**.

The current product is **not intended to be a replacement for platforms such as Property24 or Zillow**. It is the online presence and lead-generation platform for an individual realtor.

## Core User Journeys

### Buyers

Browse properties → View property → Enquire → Request viewing → Realtor follow-up

### Renters

Find rental properties → Filter/search → View property → Request viewing → Rental enquiry → Realtor follow-up

### Sellers

Learn about selling services → Request consultation/valuation → Provide property information → Qualified seller lead

### Landlords

Learn about letting/property management services → Submit enquiry → Provide property/landlord information → Qualified lead

## Development Documentation

Development sessions are documented separately in the `notes/` directory.

Each session records what was worked on, what was learned, decisions made, and the state of the project at that point.

This allows the repository to show not only the final product, but also the development process behind it.

## Project Scope

The current focus is the **realtor website**.

A more advanced real-estate application may eventually be developed separately to support operational functionality such as:

* Property management
* Tenant management
* Maintenance
* Inspections
* Reports
* Realtor administration

These features are intentionally outside the scope of the initial website.

## Project Goal

Build a professional, responsive, accessible, and maintainable realtor website that demonstrates practical web-development skills while solving a realistic business problem:

> **How can a realtor use their website to establish trust, showcase properties, and convert visitors into clients?**
